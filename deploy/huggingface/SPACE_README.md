# Cardiac Function AI

Upload an apical four-chamber echocardiogram; the app outlines the left ventricle on every
frame and estimates the ejection fraction (EF) with a screening risk flag.

**Screening aid only - not a diagnosis.** Source code, documentation and model card:
see the GitHub repository linked from the project owner's profile.
